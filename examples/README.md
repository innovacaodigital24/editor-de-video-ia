# Exemplos de marca

Perfis **fictícios** de `marca.json` para você ver como ficam marcas diferentes. O assistente gera o seu na entrevista de marca; use estes só como referência ou ponto de partida.

| Arquivo | Estilo |
|---|---|
| `marca-clinica-aurora.json` | Saúde: verde-água sobre fundo petróleo, ritmo calmo, vocabulário cuidadoso (sem "cura" nem "garantido") |
| `marca-consultoria-vertice.json` | B2B: âmbar sobre azul-noite, ritmo dinâmico, cortes agressivos |

Para usar um deles: copie para a pasta do projeto como `marca.json`, ajuste e rode `rodar.py validar --marca marca.json`.
Para uma fonte diferente da Montserrat/Inter (ex.: Poppins): `rodar.py fonte "Poppins"`.
